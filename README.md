# MN-IgAN-Proteomics

R scripts for plasma proteomic analyses of CKD stage and kidney outcomes in membranous nephropathy (MN) and IgA nephropathy (IgAN).

## Scripts

- `01_CKD_stage_association.R`: Associations between plasma proteins and CKD stage.
- `02_GO_enrichment.R`: Gene Ontology enrichment analysis.
- `03_Cox_progression_analysis.R`: Cox regression analyses of kidney outcomes.
- `04_machine_learning.R`: Machine learning prediction models.
- `05_nested_cross_validation.R`: Nested cross-validation for robustness analysis.
